V4.5 vs V5 DESERIALIZER COMPARISON (key structural differences):

v4.5 m():  W = i(l)                  — 1 byte header
           for e=0, a(l)-1, 1 do C[e]=m(); end   — NESTED chunks (m calls itself!)
           for d=0, a(l)-1, 1 do ... constants via i/a/d ...

v5    _():  M = d(n)                 — 2 bytes first
            for d=0, a(n)-1, 1 ...   — flat constants loop

IMPORTANT: v4.5's m() reads 2 header fields (i + a) before the const loop;
v5 reads d() first (M). Both are consistent formats — just evolved.

CRITICAL REALIZATION: v4.5's LZW varint reader r() uses

    l += 1

27-digit code => impossible for an LZW over a 256+ dict UNLESS v5's dict is
bigger OR the alphabet/base differs OR v5 seeds the dict with MANY entries.
